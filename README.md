# Herculean - A Pumped-Up Exercise Tracker
## Description
Herculean is a comprehensive exercise tracking application designed to help users monitor their fitness routines and progress. 
### Current Features include:
- User Accounts: Login and registration system.
- Exercise Logging: Record various types of exercises with details such as duration, intensity, weight, etc.
    - Custome workout: Users can create their own custom workout if none is available
- Themes: Users can choose between different themes (currently just light and dark)
- User customization: Users can change their user name, email, and password as they desire
- LLM Assistant: Get workout suggestions and tips from an AI assistant.
- User goals: Users can set personal goals

### Future Features:
- Workout Plans: Create and manage personalized workout plans.
- Progress Tracking: Visualize your fitness journey with charts and statistics.
- Leaderboard: Compete with friends and other users to stay motivated.
- Profile Customization: Personalize your profile with avatars and other items.
- Holiday themes: Additional themes that are based on holidays

## Usage
To run this project, install the app-release.apk file from app/releases section into your Android device.
To run this project without an Android device, install an emulator (Android Studio has one) and run it on that device.
